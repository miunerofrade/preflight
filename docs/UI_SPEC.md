# Preflight UI spec

此文档是本仓库界面的约束，适用于中英文、文本、文件、网址、批量模式、详情浮层和新增组件。

## 布局与网格

- 优先采用 12 栏网格。桌面卡片占 4 栏，中等宽度占 6 栏，窄屏占 12 栏。
- 当前断点为 840px 和 600px；跨模式复用相同断点。
- 栏间距 16px，面板内边距 24px，窄屏 20px。优先使用现有 CSS 变量。
- 标题、评分、正文、操作入口依照同一对齐线排列。相似卡片的标题区、文字行距、内边距和交互一致。
- 同排卡片等高。窄屏按内容排版，避免用占位标签或空说明凑高度。
- 长详情在共用浮层中查看，不在卡片内展开长内容或嵌套滚动区域。

## 颜色、材质与可访问性

- 按钮、进度条、状态指示使用纯色，禁止渐变背景或渐变光带。
- 装饰性色块须有明确美观作用；不为填充空间添加装饰。
- 默认无边框，优先使用浅色阴影和留白分隔区域。边框仅用于必要的区域分割、引用或风险定位。
- 键盘焦点轮廓必须保留，不能为了无边框外观移除 focus-visible。
- 按 WCAG AA：普通文本与背景的对比度至少 4.5:1；大文字至少 3:1；必要的控件、焦点和状态图形至少 3:1。
- 颜色不能成为唯一的信息载体。风险必须同时有明确文字；浅色进度槽只是辅助，数值以文本提供。
- 复用现有颜色变量。新增颜色或背景时计算实际前景与背景的对比度，包括悬停和选中状态。

## 字体

- 所有可读界面文字不小于 14px，包括辅助说明、代码和详情元数据。
- 字号优先为 4 的倍数：16、20、24、32px；14px 仅用于必要的次要信息，不继续缩小。
- 统一中文无衬线字体，按钮和表单继承字体；代码使用等宽字体。
- 推荐字号与行高：14/20、16/24、20/28、24/32、32/40px。相似文字使用相同行高。

## 信息与状态

- 不用“未发现”“未检出”“无需检查”等无信息增量的说明或胶囊占据空间。
- 正常检测结果保留必要的分数或数量，不重复添加正常状态标签及正常分类进度条。
- 复检只列出未解决的检查项。检查失败、检查缺失、风险未解决不能因精简界面而被隐藏或伪装为正常。
- 可复制、人工确认、复检未通过的处理稿应有一致且明确的行为，不用颜色替代处置文字。
- 减少胶囊，优先使用简洁的文字状态和对齐后的事实列表。
- 不用小字反复解释点击、展开、复制等显而易见的操作；保留会影响用户判断的信息。
- 禁止使用中点字符 U+00B7 组织并列元素。事实项用网格、行列、列表或独立文本元素排列，完整句子使用正常标点。
- 中英文遵守同一结构、相同组件和信息层级，不只修改某一种语言。

## 维护与验证

- 每组完成的改动及时 commit，提交信息说明最终行为。
- UI 改动按需执行语法检查、现有交互检查和颜色对比度计算，不为简单样式修改扩建测试体系。
- 未经用户要求不做截图或视觉检测。清理本次任务产生的临时文件。
